# Домашнее задание к работе 7.
## Описание

### Вариант 33
Программа запрашивает тип фигуры и её параметры, после чего вычисляет и выводит результат (площадь или полупериметр).
## 1. Алгоритм и блок-схема 
### Алгоритм 
1. **Начало.**
2. **Объявить** переменную `f` (символ) для фигуры и переменные `a`, `b`, `c` (вещественные числа) для параметров.
3. **Запросить** у пользователя букву фигуры (`t`, `s`, `o` или `r`) и считать её в переменную `f`.
4. **Проверить** значение `f` (оператор выбора `switch`):
   * **Если `f == 't'`**: запросить 3 числа (`a`, `b`, `c`), вычислить `(a + b + c) / 2` и вывести результат.
   * **Если `f == 's'`**: запросить 1 число (`a`), вычислить `a * a` и вывести результат.
   * **Если `f == 'o'`**: запросить 1 число (`a`), вычислить `3.14159 * a * a` и вывести результат.
   * **Если `f == 'r'`**: запросить 2 числа (`a`, `b`), вычислить `a * b` и вывести результат.
   * **Иначе** (если введена другая буква): ничего не делать (программа просто завершится).
5. **Конец.**
